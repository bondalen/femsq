## Как пользоваться

1. При старте фичи C2–C5 — найти группу(ы) по этапу P2.
2. Открыть `raw/` и `VBA-Code-Export/` только для **затронутых** объектов.
3. Решение «перенести / упростить / оставить в Access / вне объёма» фиксировать в плане фичи, не дописывая обязательную колонку сюда.
4. Вопросы В1–В8 из `03-processes` закрывать **по мере** касания соответствующих этапов, не заранее.
