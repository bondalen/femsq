# Инструкция оператору: сбор инвентаризации Access (C1)

**Машина:** Windows с MS Access и рабочим файлом освоения.  
**Важно:** все шаги — на **копии** файла. Рабочий оригинал не открывать модулем каталога.

## 1. Копия файла

1. Закрыть Access с рабочим файлом.
2. Скопировать `.accdb` / `.mdb` в отдельную папку, например `C:\temp\femsq-c1\`.
3. Дальше работать только с копией.

## 2. Повторный ExportAllModules (код VBA)

1. Открыть копию в Access.
2. Импортировать / убедиться, что есть модуль `vba_export` с процедурой `ExportAllModules`  
   (из репозитория: `docs/project/proposals/vba-analysis/VBA-Code-Export/Standard-Modules/vba_export.bas`).
3. Immediate: запустить `ExportAllModules` (путь выгрузки — как в модуле, обычно рядом с файлом).
4. Перекодировать выгрузку CP1251 → UTF-8 (как в коммите 2026-08-07) и передать папку агенту  
   для замены `VBA-Code-Export/` в git.

Январская выгрузка в репозитории **устарела** (до `_2605`).

## 3. Каталог объектов (`modC1Catalog`)

1. Access → VBA → File → Import File… →  
   `docs/project/proposals/vba-analysis/c1-inventory/modC1Catalog.bas`  
   (модуль должен называться `modC1Catalog`, не `DumpC1Catalog`).
2. Immediate:

```text
DumpC1Catalog "C:\temp\c1-inventory"
```

3. Дождаться `DumpC1Catalog DONE` в Immediate.
4. В папке появятся:
   - `forms.tsv`, `reports.tsv`, `queries.tsv`, `macros.tsv`, `linked-tables.tsv`
   - `queries\*.sql` — тексты запросов

Формы и отчёты открываются в конструкторе **скрыто** и закрываются **без сохранения**.  
Ошибка по одному объекту пишется в файл / Immediate; остальные продолжают обрабатываться.

## 4. Что передать в чат

1. Папка `C:\temp\c1-inventory\` (архив zip).
2. Новая выгрузка VBA (UTF-8).
3. Имя и путь исходного рабочего файла (без секретов) + дата копии.

## 5. Чего не делать

- Не запускать на единственном рабочем файле без копии.
- Не сохранять формы/отчёты после открытия конструктором.
- Не править объекты «заодно» во время выгрузки.
