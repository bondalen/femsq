1. `sql/MSSQL2012/01_CREATE_ra_change_au.sql`

4. `sql/MSSQL2012/04_SEED_ra_at_types_2_6.sql` — если в `ags.ra_at` нет ключей 2..6

## 5. Критерий вывода JAR 156 (§2.4) — зафиксировать **до** выкладки кандидата

Вывод 156 разрешён только когда **все** пункты выполнены и записаны в журнале:

| # | Критерий | Как подтвердить |
|---|----------|-----------------|
| 1 | Кандидат стартует на проде рядом с 156 | version + connection/status на порту кандидата |
| 2 | Health/UI кандидата на прод-схеме без M6 | status; СУДЗ disabled без падения ядра |
| 3 | Ревизии **3, 6, 5** через кандидат (по одному типу) | COMPLETED; type 5 без 2601 на UX |
| 4 | Smoke освоения `_2606` (или принятый отчёт `mstrg`) на проде после факта | RS1/RS4 не пусты / отчёт без фатала |
| 5 | DDL Au применён; VERIFY PASS; 156 при этом **ещё** может работать | `03_VERIFY_after` |
| 6 | Решение владельца: кандидат принят как действующий | запись в журнале + обновление `project-docs.json` → `application_server` |

До выполнения §5–6 каталог `26-0716-1600` **не** удалять (откат).
