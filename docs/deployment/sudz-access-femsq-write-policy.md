## 0. Цель

После cutover на FishEye оператор ведёт квартальный цикл **без Access** для шагов контура B. Access остаётся только там, где явно разрешено ниже, либо как **read-only** на период dual-read.

Пока решение владельца по строке не подписано — считать режим **«FEMSQ пишет; Access не пишет в те же объекты»**.

---

## 1. Матрица «кто пишет»

Легенда: **F** = FEMSQ · **A** = Access · **—** = не используется / запрет · **R** = только чтение.

| Объект / шаг БП | До cutover (сейчас) | Сразу после H (цель) | После dual-read off (I) |
|-----------------|---------------------|----------------------|-------------------------|
| Общий свод → воронка C / `DbtValue` | F (DEV) / A (prod legacy) | **F** | **F** |
| `export_*` → воронка D / `cn_inv_pm` / `g_p` | F (DEV, 0076) | **F** | **F** |
| Rslt сбор / повтор Excel | F | **F** | **F** |
| Импорт возврата → `yr_CmmGr_New` | F | **F** | **F** |
| Правка «старых» cmm в `yr_CmmGr` | F (+ A legacy) | **F**; A = **R** или запрет | **F** |
| D644 · Выгрузить / Свод · Выгрузить | F (S59 DEV) | **F** | **F** |
| Краткий отчёт до БД (БП 1.1.1.0) | Excel вручную / Access VBA | **F** (после `.3.*`) | **F** |
| Словарь FIO `ags.fioDict` | — (seed DEV) | **F** CRUD | **F** |
| Справочники договоров / ExistCtpt (0071) | F + A | **F** основной; A — только согласованный хвост | **F** |
| Прямой SQL/макросы Access в `ags`/`yr` под отчёты Rslt/D644 | A | **—** (запрет на запись) | **—** |

**Не путать:** исходящий годовой **Свод · Выгрузить** (БП 1.2.1) ≠ краткий отчёт по входящему своду (БП 1.1.1.0).

---

## 2. Правила конфликта

1. **Один писатель на объект в окне квартала.** Если FEMSQ уже выгрузил/записал срез или группу cmm — Access **не** перезаписывает те же строки.
2. **Исключения** только письменным решением владельца (дата, объект, срок, кто откатывает).
3. На период dual-read (фаза I cutover): Access может **читать** старые `*InvAccnt` для сверки; запись в new-слой (`invDbt` / `Dbt` / `DbtValue`) — **только FEMSQ**.
4. Файлы на шаре (`excel/…/debit/`): FEMSQ пишет результаты рядом с входом (`*_краткий_отчёт.xlsx`, Rslt/D644 в выбранную папку Progress). Access не «подменяет» эти файлы тем же именем без пометки `_access_`.
