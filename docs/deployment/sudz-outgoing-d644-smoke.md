## 1. Кто запускает

| Роль | Действие |
|------|----------|
| Оператор СУДЗ | Progress → операция → папка → Выгрузить; сохранить файл на шару квартала |
| Владелец / контролёр | Сверка с эталоном (§3); подпись в журнале smoke |
| Access | **Не** пересобирает парный `ags_Yr_DbtChangesRsltD644_*` для того же yr/среза |

---

## 2. Порядок smoke (один `yr`)

```text
1. Открыть год A0 → Progress
2. Убедиться: yr_CmmGr = группа после вехи 1.1.3
3. Срез currUpl = крайняя выгрузка квартала (как для сдачи)
4. D644 · Выгрузить → файл в папку
5. (Если Q4 или тех.smoke) Свод · Выгрузить → файл в папку
6. Заполнить §3 и §4; запись в журнал проекта
```

Ожидаемо в логе Progress: операция завершена без uncaught error; путь/имя файла видны оператору.

## 5. Отказ / повтор

| Симптом | Действие |
|---------|----------|
| Пустой D644 / нет счетов | Проверить cmm в `yr_CmmGr`, currUpl, seed портфеля; не чинить Access-запросом |
| Расхождение с эталоном Access | Сначала политика (кто писал cmm); затем баг FEMSQ vs устаревший эталон |
| Свод «нули» вне Q4 | Ожидаемо ослабить критерий; не блокировать cutover smoke D644 |
