## 1. Назначение

Единый целевой каркас **верхней строки меню (TopBar)** и распределения доменных экранов Java-приложения с учётом:

- перечня топ-форм MS Access (обследование `VBA-Code-Export`);
- уже существующих пунктов Java;
- Java-only возможностей без прямого Access-аналога;
- визуального ориентира **Cursor IDE** (плоская оболочка, плотный status bar).

Access **не имеет** аналога TopBar — формы открываются из панели объектов. Данный документ описывает **IA Java**, а не 1:1 перенос меню Access.

## 2. Роли полос (Design chrome)

```text
┌─ TopBar ── продукт + доменная навигация (+ overflow) ─────────┐
│ FEMSQ │ Организации │ Стройки ▾ │ Инвестиции ▾ │ … │ Сервис ▾ │
└───────────────────────────────────────────────────────────────┘
│                         контент                               │
┌─ StatusBar ── техсостояние + системные действия ──────────────┐
│ ● Подключено · схема │ сообщение… │ тема │ logout             │
└───────────────────────────────────────────────────────────────┘
```

| Полоса | Содержит | Не содержит |
|--------|----------|-------------|
| **TopBar** | Бренд, пункты доменов, подменю, xs-overflow | Chip статуса, «Подключение к БД», тема |
| **StatusBar** | Индикатор соединения (клик → модалка), схема/БД, `message`, тема, logout | Доменную навигацию |

**Сообщения:** статус соединения и операционные строки оболочки — в StatusBar. `$q.notify` — только для редких действий внутри экранов (не дублировать connection).

**Системное (не TopBar):** Подключение к БД, переключатель темы — **StatusBar**.

## 4. Темы (вариант B)

| Решение | Содержание |
|---------|------------|
| Две темы | **Kimbie Dark** (по умолчанию) и **VS Light** |
| Геометрия | **Одинаковая** для обеих тем (радиус, кегль, отступы nav/status) |
| Меняется | Только цветовые токены `--femsq-*` |
| Light | Сохраняется: удобна на глянцевых экранах (меньше бликов от окружения) |

Референс визуала оболочки: Cursor (тёплый dark, плоские контролы, узкий status). Не копировать IDE 1:1 — перенять принципы плотности и единообразия.

---

## 5. Геометрия контролов (анти-«попугай»)

| Правило | Значение |
|---------|----------|
| Радиус | один токен `--femsq-control-radius` (≈ 4px) |
| Nav | плоские text/icon items одного веса; active = фон/нижняя черта + primary |
| Без mix | не смешивать `round` / `unelevated rounded` / `flat rounded` в chrome |
| Типографика оболочки | базово **13px** (`--femsq-chrome-font-size`); бренд FEMSQ — тот же кегль, `font-weight: 600` |
| Типографика контента | заголовок экрана = FEMSQ (13px, `.femsq-page-title`); **строчный текст/таблицы/дерево = 12px** (`--femsq-content-body-size`) — **строго меньше** пунктов TopBar (13px). Quasar `td { 13px }` переопределён. Не использовать `text-h6` |
| Иконки | outline, один размер (~18px) |

## 6. Принципы IA

| Правило | Смысл |
|--------|--------|
| Верхняя строка = домены | Не каждая Access-форма — кнопка меню |
| Подформы `_gt_*` | Остаются внутри экрана |
| Отчёты | Один пункт; варианты `mstrgAg_*` — в каталоге/контексте |
| `cst` / `cstAgPn` | Раздел **Стройки** |
| Test Grid | Только **Сервис** |
| Корректировка IA | Допускается; обновлять `lastUpdated` |

## 7. Карта покрытия (Access ↔ Java)

| Раздел | Access (топ-формы) | Java |
|--------|--------------------|------|
| Организации | — | есть |
| Стройки | `cst`, `cstAgPn` | план 0058 |
| Инвестиции → Цепочки | `ipgCh`, `ipgChMin` | есть |
| Инвестиции → прочее | `ipg*`, `stNet*`, … | нет |

| Отчёты | `Report_*` | каталог есть |
| Сервис / Test Grid | — | есть |
| Подключение / тема | — | StatusBar |

## 8. Общие подходы к дизайну доменных экранов

1. **Master–detail** — список слева / карточка справа.  
2. **Вложенный контекст** — вкладки/панели, не новые пункты TopBar.  
3. **Смена текущей записи** — перезагрузка дочерних наборов.  
4. **GraphQL + Apollo** для домена.  
5. Темы: Kimbie / VS Light, **общая геометрия** (вариант B).  
6. Без скриншотов Access — MVP по полям БД и VBA-поведению.
