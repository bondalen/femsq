### Постоянный layout приложения
**Роль каркаса**: обеспечить пользователю неизменные точки доступа к подключению к БД и спискам организаций, а также постоянно показывать текущее состояние соединения и выбранной схемы.

**Верхняя панель**
- Логотип/название продукта слева (единый кегль с chrome, без конкурирующего subtitle).
- Доменная навигация (плоские пункты): Организации, Отчёты, Инвестиции, Ревизии, Сервис.
- Подключение к БД и тема **не** в TopBar — см. нижнюю строку состояния (`02-4_app-forms-ia.md`, Design chrome A0).
- Индикатор активного раздела (фон + нижняя черта) облегчает навигацию.

**Основная область контента**
- Занимает всё оставшееся пространство. На этапе каркаса содержит placeholder: приветственный текст, подсказки по подключению и динамически сменяемый контент экранов.
- Поддерживает responsive-верстку; при ширине &lt; 768px навигация верхней панели сворачивается в overflow-меню.

**Нижняя строка состояния**
- Слева: кликабельный индикатор соединения (открывает модалку подключения); при ошибке — краткий текст рядом.
- По центру: текущее сообщение / прогресс (или «—»).
- Справа: схема/БД, пользователь (если есть), переключатель темы, logout при `connected`.

**Состояния каркаса**
- `idle`: доменные пункты (кроме всегда доступных) отключены; StatusBar — «Не подключено»; клик по индикатору открывает модалку.
- `connecting` / `disconnecting`: StatusBar отражает прогресс; доменная навигация по-прежнему зависит от `connected`.
- `connected`: доменные экраны доступны; StatusBar показывает схему/пользователя.
- `connectionError`: StatusBar в negative-тоне + текст ошибки; повторное подключение — через индикатор/модалку.

**UX-подсказки**
- Tooltip на индикаторе соединения и иконках темы/logout.
- Цветовая точка статуса дополняется текстом.
- Темы: Kimbie Dark (default) + VS Light; геометрия chrome общая (вариант B).
