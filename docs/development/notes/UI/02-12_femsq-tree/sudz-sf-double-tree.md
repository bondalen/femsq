# S68 / `sudz-sf-double`: дерево (исторический конспект)

**Актуально для walker:** [ksdsf-inv-num.tree.md](./ksdsf-inv-num.tree.md) — корень `invNum` выбранной строки списка, не «группа совпавших номеров» внутри дерева. Правила экземпляров: [relation-tree.md](./relation-tree.md).

Ниже — **ранний** конспект «от совпадающего СФ (`inv`) вверх», H1 ручного builder. Сохранён как память; новые правки карты КСДСФ — в `ksdsf-inv-num.tree.md`.

**H1 (2026-08-18):** renderer — `FemsqTree`. Builder — `src/utils/sudz-sf-double-tree.ts` (до замены обходником).

Цель дерева: в правом нижнем блоке экрана выбрать “СФ с совпадающим номером” и показать его связи “вверх” до “конца” (как вы определяете), включая историю задолженностей и “старую”, и “новую” структуры.

Правило оформления узлов:
- `Заголовок узла` = минимум полей, по которым узел однозначно узнаётся и с ним удобно работать (ключи + человекочитаемые номера/типы).
- `Деталь узла` = расширенная карточка/набор полей (всё, что может быть раскрыто внутри узла).
- Если информации/полей для детали пока нет (или их ещё нужно уточнить) — в `Деталь узла` пишем `...`.
