Верхний список — не часть этого дерева: там все совпадения номера Excel. Здесь один корень — `invNum` выбранной строки. Соседние `inKey` с тем же `inNumNull` в дерево не кладём.

Правило оформления узлов:
- `Заголовок узла` = ключи + узнаваемые номера/типы.
- `Деталь узла` = расширенная карточка.
- Если полей ещё нет — в детали `...`.
- `1:N` — сначала папка-пустышка, под ней строки. `N:1` / `1:1` — сразу запись.
