## Итог на DEV

Официальная группа — **1909** «[sudz] QII 2026 re-import *Dv (comm_26-1012)». У годов **901** и **909** `yr_CmmGr` = **1909**. У года 901 `yr_CmmGr_New` тоже **1909**. Группа **907** переименована в SUPERSEDED и снята с указателей; удаление отложено. Группы **903–906** не переписывались: у них нет указателя года.

Д644, год 901, срез 903, группа 1909: **176** комментариев, счета 74 / 63 / 39, долг 11897 — две строки по 18 000. Комментарий сажается walk-back: доля крайней выгрузки года, затем предшествующие, затем якорь счёта. Зерно комментария, кода стройки и агента — фактическое зерно `DbtValue`, не база целиком.

В книге Rslt блок «старых» комментариев стоит сразу после фактов предшествующего среза. Колонки `*_new` — в конце, после крайней группы. Импорт `*_new` идёт по техническим именам колонок.
