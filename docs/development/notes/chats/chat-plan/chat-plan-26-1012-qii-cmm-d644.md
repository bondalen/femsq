## 0. Цель

Записать ответы специалистов по мероприятиям II квартала 2026 в **новую** группу комментариев и получить построчный документ Д644, переключив год **901** на эту группу.

**Критерий закрытия:** у года 901 поле `yr_CmmGr` указывает на новую группу; содержимое групп **905** и **906** не изменено; файл Д644 снят со среза **903** (состояние на 30.06.2026); «Комментарий Филиала 644» совпадает с `mery_new` файла там, где он заполнен. Весь путь пройден кнопками UI.

**Вне scope:** годовой свод по счетам (он сдаётся по итогам IV квартала); прод и cutover; правка короткого имени `S58`, которое UI пишет в `cnicgNmCs` при создании группы; слияние с группой 905.

**Что UI уже даёт без доработки:** карточка года — комбо `yr_CmmGr` и «Сохранить»; Progress — «Создать» группу, файл возврата, «Rslt повтор · Выгрузить», «D644 · Выгрузить» и выбор среза.

**Пробел, закрытый узлом 1.0:** экран «Долги / мероприятия» показывал и сохранял только официальную группу. Пока `yr_CmmGr` и `yr_CmmGr_New` различаются, официальные поля только для чтения, правка и снятие строк — кнопкой «Сохранить в группу новых».

## 1. Исходные факты

Год **901** «Основной вариант 2026-го года»: база `upl` **901** (состояние 31.12.2025), срезы **902** (31.03.2026) и **903** (30.06.2026). Официальная группа `yr_CmmGr` = **905**. Рабочая `yr_CmmGr_New` = **906** (майский черновик). В **906** этот файл не загружать: импорт дополняет текущую рабочую группу, а не заменяет её.

В Access и в `sudz.Yr_DbtChangesD644` исходящий документ читает **одну** группу — ту, на которую смотрит `yr_CmmGr`. Соседние группы не участвуют. Пустое мероприятие в выбранной группе даёт пустой комментарий филиала. Пустой код стройки в группе заменяется кодом среза, иначе кодом базы года.

Файл — возврат Rslt. Строка 3: `dbtKey`, `cur_new`, `mery_new`, `cstAgPn_new`. Колонка `Проверено` — пометка специалистов для себя; в загрузку и в Д644 не входит (решение 2026-10-12).

| Факт по файлу | Значение |
|---------------|----------|
| Строк с непустым `*_new` | 179 (счета 606012 — 77, 762210 — 63, 767502 — 39) |
| Уникальных `dbtKey` | 178; ключ **11897** записан дважды одним текстом |
| Мероприятия | 179; из них 145 отличаются от зелёной колонки, 34 совпадают |
| Куратор | 171 (33 новых, 1 изменён) |
| Код стройки | 158; изменён один: долг **3672**, `056-1001888` → `051-1001888` (оба кода есть в `ags.cstAgPn`) |

В группе 905 сейчас 180 мероприятий, 131 куратор и около 1815 кодов строек. После переключения указателя эти строки в Д644 не подмешиваются. Среди кодов 905 есть **70**, которые отличаются от среза 903: у долгов, не попавших в новую группу, в Д644 встанет код среза.
