### 4.1. Как читать расхождения QII

Совпадение с временной книгой само по себе путь через платежи не подтверждает: перенос мог совпасть с выгрузкой. Каждая отличающаяся ячейка попадает в один класс:

| Класс | Что видно | Вывод |
|-------|-----------|--------|
| Поправка | в итоге код из выгрузки QII, во временной книге — перенос с прошлого квартала | путь через платежи подтверждён |
| Пусто в выгрузке | в выгрузке стройки нет, во временной книге код был перенесён | итог следует выгрузке; строка остаётся в списке разбора |
| Дефект | код в итоге не равен ни выгрузке, ни переносу | загрузка или сборка; лист **.8.9** не закрывается |

### 4.2. Четыре кода книги 767501 в эталонах Rslt (2026-10-20)

Коды из платежей pm **61** / книги `export_26-0130_767501`: **014-2007423**, **014-2007424**, **051-2007134**, **051-2007135** (18 платежей, `cnipCstAgPn` пуст).

| Файл | Что искали | Результат |
|------|------------|-----------|
| Архив `2026-1019.zip` → `ags_Yr_DbtChangesRslt_26-0505.xlsx` | те же коды | Архив AES; чтение — копия на шаре (тот же диапазон по плану). Колонки строек только **QIV** и **QI**; колонки **QII** нет. Четырёх кодов **нет** (ни полных, ни хвостов) |
| Временный QII asOf903 `…_s81_cmm_28469fix_26-0916.xlsx` | те же коды в «2026. II-й квартал. Код/Наименование стройки» | Четырёх кодов **нет**. Колонки QII есть |

В платежной книге Excel коды есть, имён строек нет (только код и агент). Имена для каталога эталон Rslt не подсказывает — оператор вносит стройки на экране строек (**1.2.4**).
