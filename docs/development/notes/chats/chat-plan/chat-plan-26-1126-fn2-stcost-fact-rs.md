## 0. Зачем

Бизнесу нужны срезы освоения **по структуре затрат**:

```text
212 (Всего) = 195 (СМР) + 172 (оборудование) + 187 (прочие)
```

Лимит в RS `_2606` уже аддитивен (после C2 §3.7). **Факт в RS — нет:** при `@stCostKey∈{195,172,187}` `ag_presented*` ≈ полный объём (как при 212), сумма частей ≈ **3×212**. Такой отчёт бесполезен.

Корень: в `fnIpgChRsltCstUtl2_2606` для агентской схемы (`iShKey=2`, `shShow`) факт берётся из **`RRcTimeList` / `@raFact2408`** без фильтра `@stCostKey`; lim — из mastering (stCost-aware).

**Цель плана:** при `@stCostKey NOT NULL` факт agency в RS режется по stCost так же, как lim; критерий приёмки — **аддитив факта в RS** на цепи 507.
