## 0. Цель

Довести экран D до операционного паритета Access `CnInvPmtUpl>File_f` **после** успешной воронки: живые нижние вкладки, вкладка «счета, сумма», ручной разбор СФ (в т.ч. InvNot left>0 и TwoLoad), связь с КСДСФ/`g_p`, UX лаунчера.

**Критерий закрытия:** оператор на DEV (пакет вроде pm=59) после flLoad видит N на вкладках, разбирает хвост СФ/строек из UI (не только HTML-лог), видит Sum_t и статус связи `g_p`; UAT чеклист vs [02-11](../../UI/02-11_cn-inv-pmt-upl-access.md) пройден.

**Вне scope:** правка канона apply InsPm/InvNot set-based; прод-cutover; Excel-бэкфилл S80; полный CRUD договоров/строек на D (deep-link в существующие экраны).
