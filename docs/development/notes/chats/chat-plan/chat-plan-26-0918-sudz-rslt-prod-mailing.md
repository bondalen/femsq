## 0. Цель

**Обеспечить на продуктивном FishEye поддержку квартального бизнес-процесса СУДЗ (P1) в контуре B:** оператор без Access готовит данные и документы цикла **краткий отчёт по полученному своду (до БД) → загрузка свода → стройки (`export_*`) → Rslt (сбор / возврат / повтор) → веха комментариев → исходящие D644** (и **свод по счетам** — по итогам Q4).

Критерий достижения (черновик): один релиз на проде закрывает продуктный путь **БП 1.1.1.0 + БП 1.1.* + БП 1.2.1**. Согласование разделов и направление письма (БП **1.2.2–1.2.3**) — вне продукта.

Разовая рассылка asOf903 с DEV (S82) **цель не закрывает**.  
Контур A (только до Rslt без исходящих) **отклонён** — прирост ценности B при сопоставимых трудозатратах.
