## 1. Цель v1 (этот план / задача 0072)

Экран **D** «Загрузка платежей» (`sudz-pmt-upl`):

1. **Сверху** — список всех `cn_inv_pm_upl` (дата, имя, ключ), не дети одной дбт-выгрузки.
2. **Середина** — вкладка «загрузка»: путь, лист (`cipufSheet`), флаги, кнопка «загрузка» **без действия**, 13 чекбоксов шагов `cipu*` **без пресетов**.
3. **Снизу** — вкладки: ход загрузки (пустое поле лога) | повторяющиеся СФ (каркас) | стройки новые (каркас).

Код воронки, Excel, apply, `g_p`, InvDouble/CstNew live — **вне v1**.

## 2. Согласованная раскладка

```text
┌─ СУДЗ → Загрузка платежей ──── [+ Выгрузка] [Обновить] ─┐
│ список cn_inv_pm_upl (дата · имя · ключ)                 │
├─ [ загрузка ]  [ счета, сумма ✕ ]                        │
│  Файл  |  лист: [cipufSheet]                             │
│  ☑ Обновлять   ☑ обнов. по исх?   [ загрузка ]  ← stub   │
│  ☑ шаг1 … ☑ шаг13                 ← без пресетов         │
├─ [ ход загрузки ] [ повторяющиеся СФ ] [ стройки новые ] │
│  большое поле лога (пусто)                               │
└──────────────────────────────────────────────────────────┘
```

| Зона | Решение владельца (2026-08-19) |
|------|--------------------------------|
| Пресеты воронки | **не делать** (у долгов не использовались) |

| Обратная «выгрузки долгов» | **не** на v1 |

Опора UI: `SudzDbtUplView` (сплиттеры, FemsqTable списка, чекбоксы шагов). GraphQL списка уже есть: `sudzPmUplLookups`, `createSudzPmUpl`. Лаунчер File/лог для пустого каркаса не обязателен.

## 3. Реестр шагов (чекбоксы; Excel→Tbl = флаг «обнов. по исх?»)

Подписи — комментарий VBA `Процедура *…*`, кроме шага 6.

| # | stepId | titleRu |
|---|--------|---------|
| 1 | `cipuCtpt_All_OIdNot` | Отображаем отсутствующих контрагентов по выгрузке платежей |
| 2 | `cipuCacNot` | Отображаем отсутствующие стройки |
| 3 | `cipuCn_CtptCnNotLoad` | Отображаем отсутствующие договоры (по выгрузке платежей) либо добавляем их |
| 4 | `cipuCn_CtptCnTwo` | Отображаем пары договор+исполнитель более одного раза |
| 5 | `cipuCn_AgNotLoad` | Отображаем договора, не имеющие агента в БД, либо добавляем их |
| 6 | `cipuCn_AgTwo` | Отображаем агента более одного раза |
| 7 | `cipuCn_CtptCnOneInvNotLoad` | Отображаем новые счета-фактуры для существующих договоров либо добавляем их |
| 8 | `cipuCn_CtptCnOneInvTwoLoad` | Отображаем счета-фактуры, уже более чем однократно в БД (только показ; apply закрыт S69) |
| 9 | `cipuCn_CtptCnOneInvOneAcNotLoad` | Отображаем СФ без пары СФ+счёт ГК либо добавляем их |
| 10 | `cipuDocNotLoad` | Отображаем отсутствующие платёжные документы либо добавляем их |
| 11 | `cipuCn_CtptCnOneInvOneAcDcNot` | Отображаем СФ без платёжного документа |
| 12 | `cipuInsPmNotLoad` | Отображаем платежи, готовые к внесению в БД, либо вносим их |
| 13 | `cipuInsPmExt` | Отображаем платежи, уже в БД (построчный diff) |

Порядок жёсткий (префикс цепочки), как у долгов S61f — **без** кнопок-пресетов.
