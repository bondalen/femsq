| 7 | `cipuCn_CtptCnOneInvNotLoad` | Отображаем новые счета-фактуры для существующих договоров либо добавляем их |
| 8 | `cipuCn_CtptCnOneInvTwoLoad` | Отображаем счета-фактуры, уже более чем однократно в БД (только показ; apply закрыт S69) |
