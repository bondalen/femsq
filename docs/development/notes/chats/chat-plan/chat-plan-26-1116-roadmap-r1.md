## 1. Бизнес-обстановка (2026-11-16)

- **Освоение лимитов (P2)** — ежедневный процесс на `_2605` + MS Access / VBA. К процессу на базе Access много претензий бизнеса. Именно `_2606` — актуальная для бизнеса цель, **в полном объёме** (все пункты P2, не только расчёт).
- **СУДЗ (P1)** — квартальный цикл; может выполняться на DEV в течение квартала и дольше. Выкладка контура B на прод — следующий горизонт (R2).
- **FEMSQ на проде уже работает:** thin JAR **0.1.0.156** (15.10.2026) на Linux-хосте `23121PC05780077`, Java `jdk-23.0.1`, каталог `26-0716-1600`, диск X → `/mnt/Общий_(X)`. Через него выполняются ревизии актов АВ (тип 6) и аренды земли (тип 3); отчёты агентов (тип 5) — в основном Access, редко JAR 156.
- На проде допустимы **два экземпляра приложения**: действующий и кандидат, чтобы не повредить используемый функционал.
