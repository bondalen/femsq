## Каталог

### `ipgMin_*` — runtime (данные)

| Файл | Что видно |
|------|-----------|
| `ipgMin_001` | Master-список ИП + вкладка **пункты** (`ipgp*`) + низ: вкладка **планы** (UtPl Ye/Qu/Mn — пусто/мало) |
| `ipgMin_002`–`003` | То же, другие вкладки/фокус |
| `ipgMin_004` | Вкладка **группы планов** (`iuplg*` + combo агентских планов) — **G3**, не ядро 2.5.2 |
| `ipgMin_005` | Продолжение групп/планов |
| `ipgMin_006` | **пункты** + низ **пункты структуры** (`ipgpSt` / StPn) — ключевой для `ipgStPn` |
| `ipgMin_007` | Деталь пункта / соседняя вкладка |
| `ipgMin_008` | **пункты** + низ **общее** (`ipgpKey`) |

Шапка (все runtime): орг, год, №, наименование, заменившая, начало/конец, **струк.** (`ipgStRlSh`→`stNet`).

Вкладки master (под шапкой): `пункты` · `общее` · `цели инвестпрограмм` · `группы планов` · `планы` · `загрузка ут. планов`.

Вкладки детали пункта (низ): `планы` · `пункты структуры` · `лимиты` · `общее`.

## Вывод для FEMSQ §2.5.2

1. **Компоновка:** список ИП (или выбор) → шапка → грид пунктов → detail выбранного пункта (суммы/`ipgpSh`/комментарий) → привязки `ipgStPn`.
2. **Вкладки G3/G2** (`группы планов`, `планы` UtPl, `загрузка ут. планов`, `лимиты`) — в 2.5.2 только место под **ленивую** «Проверить планы» / заглушку; не грузить при open.
3. **Эталон полей** совпадает с `ags.ipg` / `ipgPn` / `ipgStPn` (уже в GraphQL 2.4.2).
4. `ipgMin` на скринах — удобный визуальный образец; целевой объём функций — как у полной `ipg` (Q1).
