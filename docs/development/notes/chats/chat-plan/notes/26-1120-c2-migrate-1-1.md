## 0. Принцип (владелец, 2026-11-20)

Access — **источник сценариев и семантики данных**, не образец архитектуры или производительности.

| Делать | Не делать |
|--------|-----------|
| Сохранять смысл полей, FK, инварианты БД (`fnSt`, unique `(ipg,cstAgPn,sh)`, членство `ipgChRl`) | Копировать разбиение форм, тонкие VBA-классы `ClassFunc`, QueryDef-хаки, медленный Load |
| Оптимизировать запросы и UX (lazy вкладки, транзакции на сервере, один экран Structure) | Переносить `ipgMin` как «лучшую» карточку; плодить экраны «как в Access» |
| GraphQL-домен + FemsqTable / feQuLib | Новые REST для домена; surrogate-ключи вместо `stiKey` |

Классы Access (`ipg`, `ipgPn`, `ipgCh`, …) — справочник полей, не шаблон сервисов FEMSQ.

## 1. Матрица migrate (1.1)

Легенда: **P** = перенести в FEMSQ · **U** = упростить / улучшить · **A** = оставить в Access до «Переключение R1» · **X** = вне объёма D1.1 / 1.1

### 1.1 Structure (G4 stIpg / stNet)

| Возможность Access | Решение | Как в FEMSQ |
|--------------------|---------|-------------|
| Просмотр схемы + дерево `fnSt` | **P+U** | Query `stNetworkTree` → один экран; не QueryDef-rewrite |
| CRUD `stNet` (type=1) | **P** | Mutations create/update |
| CRUD узла `st`+`stIpg`+`stIpgNm` | **P+U** | Одна транзакция на сервисе; не прыжки по `stIpg*` |
| CRUD ребра `stRel` + `stNetPn` / порядок | **P+U** | attach/detach/reorder на том же экране |
| Копия схемы | **P+U** | Серверный `cloneStNetwork` (узлы shared по умолчанию); алгоритм уточнить на приёмке |
| Раздельные формы `stIpg` / parent / child | **U** (не копировать UX) | Сливаем в хаб |
| Legacy `ipgSt*` / `ipgStRlSh` | **X** | Не читать, не писать в новом UI |
| Структура затрат `stNetCost` | **A→1.3** | Минимум к этапу планов (§2.0c) |
| `stiLim` / старый OUT | **X** для UI 1.1 | Истина — `stIpgOutLimPn_2606` при касании `_2606` |

### 1.2 Leaves — карточка ИП и пункты (G1)

| Возможность | Решение | Как в FEMSQ |
|-------------|---------|-------------|
| Карточка ИП (поля `ags.ipg`) | **P** | Эталон **полной** `ipg`, не `ipgMin` |
| Проверки / просмотр UtPl на карточке | **P+U** | Функционал сохранить; **не** грузить на open; lazy / по действию; SQL на сервере |
| Грид + карточка пункта `ipgPn` | **P** | FemsqTable + detail; unique `(ipg,cstAgPn,sh)` |
| Привязка к разделу `ipgStPn` | **P** | Обязательный шаг Leaves после Structure |
| `ipgMin` / `ipgMinBranch` | **X** как UX | Не воспроизводить; Branch игнор |
| VBA-классы `ipg` / `ipgPn` | **U** | Не портировать; Java/TS сервисы по полям таблицы |
| Загрузка Excel LdM | **X** в 1.1 → этап **1.2** | §2.0a отдельно |
| Полный редактор UtPl / LmMn | **X** в 1.1 → этап **1.3** | |

### 1.3 Цепи (G1)

| Возможность | Решение | Как в FEMSQ |
|-------------|---------|-------------|
| Список цепей + схема `ipgcStNetIpg` / late ИП | **P** | Расширить существующий read-экран до CRUD шапки |
| Членство `ipgChRl` (`Rl_t`) | **P+U** | Mutations add/update/remove — чтобы не уходить в SSMS |
| Кнопки mastering / Rslt / `_2408` | **X** | C3/C4; не 1.1 |
| `ipgChRl_2606` (даты) | **X** в 1.1 | Касание при C3 / выравнивании `_2606` |

## 2. Порядок реализации (вход в 2.4–2.5)

Согласовано с болью Access и §2.0c Structure→Leaves:

```text
2.4a  GraphQL Structure: tree + CRUD net/node/edge + clone (stub/heuristic)
2.5a  UI Structure (единый экран)
2.4b  GraphQL Leaves: ipg + ipgPn + ipgStPn
2.5b  UI карточка ИП (как полная ipg, UtPl-блок lazy) + пункты
2.4c  GraphQL цепи: CRUD ipgCh + ipgChRl
2.5c  UI цепей: дописать write к существующему read
2.6   Приёмка на noM6 ↔ эталон прода (структура + тестовые внесения)
```

Excel-загрузка и UtPl-редактор — **после** 2.6 по дереву вехи (этапы 5 и 4), не блокируют закрытие CRUD 1.1.

---

## 3. Инварианты и качество (обязательны при коде)

1. Не MERGE эталон прода в рабочие таблицы; тест — точечные INSERT/UI на noM6.  
2. `stiKey = stKey` после create node; не суррогат.  
3. Дерево только через `fnSt` / согласованный серверный эквивалент.  
4. Unique `Ipg_CstAgPn_Sh_Unique`; дубли Excel — детект (уже §2.0c).  
5. Multi-parent / multi-net: delete узла — **forbid**, если есть `ipgStPn` или участие в других `stNet` (политика уточняется при реализации; default строгий).  
6. GraphQL only для домена; FemsqTable / паттерны feQuLib.  
7. Оптимизация запросов — часть Definition of Done экрана, не «потом».

---

## 4. Что явно не делаем в 1.1

- Портирование Access VBA/классов 1:1.  
- Воспроизведение медленного Load полной `ipg`.  
- Legacy семейство `ipgSt*`.  
- Mastering-кнопки цепи, LdM, полный UtPl CRUD, stCost UI.  
- Выкладка на прод / изменение JAR 156.
