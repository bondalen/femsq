## 3. Формат реестра функций

Файл `docs/project/proposals/vba-analysis/c1-inventory/registry.md`:

| № | Объект Access | Вид | Этап P2 | Что делает (для оператора) | Частота | Решение | Трек / выпуск | Примечание |
|---|---------------|-----|---------|-----------------------------|---------|---------|---------------|------------|

- **Вид:** форма, отчёт, запрос, макрос, модуль, связанная таблица.
- **Частота:** ежедневно / ежемесячно / ежеквартально / редко / не используется.
- **Решение:** перенести / не нужно / вне P2.
- Строка закрыта, когда есть решение; для «перенести» — трек (C2–C5) и выпуск.

## 4. Требования к модулю-каталогу (1.1)

- Выводит в UTF-8 (`ADODB.Stream`, как в образцах) по одному файлу на вид объектов из [CAPTURE §4.2](../../../../project/proposals/vba-analysis/MS-ACCESS-OBJECTS-CAPTURE.md): формы (все, включая без кода: `RecordSource`, подформы `SourceObject`, кнопки и `OnClick`, `DateModified`), отчёты (`RecordSource`, подотчёты, `DateModified`), запросы (тип, SQL, `DateModified`), макросы, связанные таблицы (`Connect` → объект SQL Server).
- Формы и отчёты открывает в режиме конструктора скрыто и закрывает **без сохранения**; объекты не меняет.
- Запускается на **копии** рабочего файла; ошибки по отдельному объекту пишет в файл и продолжает.
- Одна процедура верхнего уровня с параметром «каталог вывода»; при неоднозначности имён (как с `DumpTableDef_Extended`) — вызов с именем модуля.
