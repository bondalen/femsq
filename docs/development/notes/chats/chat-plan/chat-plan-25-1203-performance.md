## Анализ проблем

### Проблема 1: Множественные загрузки конфигурации БД (КРИТИЧНО)
- **Симптомы:** В логах видно 2-4 вызова `Loading database configuration` на один HTTP-запрос
- **Причина:** Отсутствие кэширования в `DatabaseConfigurationService.loadConfig()`
- **Влияние:** Лишние обращения к файловой системе, потенциальное замедление API
- **Файлы:** `code/femsq-backend/femsq-database/src/main/java/com/femsq/database/config/DatabaseConfigurationService.java`

### Проблема 2: Частое сканирование отчётов
- **Симптомы:** `ReportDiscoveryService` сканирует отчёты каждую минуту (23 сканирования за 22 минуты работы)
- **Причина:** `@Scheduled(fixedDelay = 60000)` установлен слишком коротким
- **Влияние:** Избыточная нагрузка при малом количестве отчётов
- **Файлы:** `code/femsq-backend/femsq-reports/src/main/java/com/femsq/reports/core/ReportDiscoveryService.java`

### Проблема 3: Конфликт commons-logging
- **Симптомы:** Предупреждение "Standard Commons Logging discovery in action with spring-jcl: please remove commons-logging.jar"
- **Причина:** В classpath присутствует `commons-logging-1.1.1.jar`, конфликтует с `spring-jcl`
- **Влияние:** Возможные проблемы с логированием, не критично, но нежелательно
- **Файлы:** Зависимости в `pom.xml`, библиотека в `lib/` на Windows

### Проблема 4: Избыточные предупреждения об optional libraries
- **Симптомы:** 31 предупреждение о missing optional libraries (Batik, Micrometer и др.)
- **Причина:** Все предупреждения логируются на уровне WARN
- **Влияние:** Захламление логов, снижение читаемости
- **Файлы:** `code/femsq-backend/femsq-web/src/main/java/com/femsq/web/startup/LibraryCompatibilityChecker.java`

### Проблема 5: Несовпадение версий библиотек (низкий приоритет)
- **Симптомы:** В `lib-manifest.json` ожидается `spring-context-6.2.6.jar`, но используется `spring-context-6.1.19.jar`
- **Причина:** Несоответствие версий в манифесте и фактических библиотеках
- **Влияние:** Предупреждение в отчёте, возможные несовместимости
- **Файлы:** `code/femsq-backend/femsq-web/src/main/java/com/femsq/web/startup/LibraryCompatibilityChecker.java`, `lib-manifest.json`

## Риски и допущения
- **Кэширование:** При изменении файла конфигурации вручную кэш должен инвалидироваться → реализовать проверку `lastModified`
- **Thread-safety:** Многопоточный доступ к кэшу может вызвать проблемы → использовать `volatile` и `synchronized`
- **Производительность:** Увеличение интервала сканирования может замедлить обнаружение новых отчётов → приемлемо для production
- **Совместимость:** Удаление commons-logging может сломать некоторые библиотеки → проверить через тесты и сборку
- **Логирование:** Переведение предупреждений в DEBUG может скрыть важную информацию → оставить критичные предупреждения на WARN
