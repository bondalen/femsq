# Обследование прода СУДЗ (фаза A)

Только чтение. Сервер `SPB-05-NV-SQL1`, база `FishEye`, Windows auth, SSMS.

С рабочей станции asus-kubuntu / nb-win этот хост не резолвится. Скрипт запускается в сессии, где продуктив открыт.

Файл: `00_SURVEY_readonly.sql`. Все сетки результата принести в чат Cursor. Ожидание зерна S73 на старом срезе DEV было 11 897 пар `(iKey, ciaName)`; на проде число пересчитывается этой сеткой `grain`.
