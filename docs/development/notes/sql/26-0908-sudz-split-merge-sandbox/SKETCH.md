# Макет Rslt — песочница split/merge

Откройте Preview. Канон полос — Excel-листы A и C: `ags_Yr_DbtChangesRslt_sm_sandbox.xlsx`.

**Как читать:** «↑ слито с строкой выше» = в Excel одна ячейка, растянутая на две строки. «Старые» комментарии — зерно `DbtValue` **предшествующего** среза (в полосе A: 201 при факте 202), не крайней полосы фактов. `*_new` на рассылке пустые; в макете колонка «новые» показывает зерно **текущего** раунда — как после возврата Excel в БД (Rslt повтор).

## Долг 111 — сколько строк на срезе

| выгрузка | число Value | сумма |
| --- | --- | --- |
| 201 | 1 | 36000 |
| 202 | 2 | 36000 |
| 203 | 2 | 36000 |
| 204 | 2 | 36000 |
| 205 | 2 | 36000 |
| 206 | 2 | 36000 |
| 207 | 2 | 36000 |
| 208 | 2 | 36000 |
| 209 | 2 | 36000 |

201: целый → 202–209: split 2×18000 → 210: снова целый.

## Полоса A — крайний 202 (две строки факта), старые с 201 (одна ячейка)

Как если открыть QI на 202, а «старые» взять с 201.

| факт 202 | старые комментарии (201) | новые комментарии (202) |
| --- | --- | --- |
| 18000 | 111 ещё целый 36000 (до split) · углубленно | 111 доля A 18000 (CN-301) · углубленно |
| 18000 | ↑ слито с строкой выше | 111 доля B 18000 (CN-302) |

## Полоса B — крайний 201 (одна ячейка факта), старые с 202 (две ячейки)

Обратная картинка: смотрим «назад» с целого среза на уже разделённый.

| факт 201 | старые комментарии (202) |
| --- | --- |
| 36000 · одна ячейка на две строки | 111 доля A 18000 (CN-301) · углубленно |
| ↑ слито с строкой выше | 111 доля B 18000 (CN-302) |

## Полоса C — крайний 210 (снова целый), старые с 209 (ещё две доли)

После обратного слияния на 210: факт снова одна ячейка 36000, комментарии предшествующего среза остаются двумя.

| факт 210 | старые комментарии (209) |
| --- | --- |
| 36000 · снова целый после merge-back | 111 доля A 18000 (ещё split на 209) · углубленно |
| ↑ слито с строкой выше | 111 доля B 18000 (ещё split на 209) |

## Долг 112 после слияния канонов (срез 201)

| слот | сумма | комментарий | группа |
| --- | --- | --- | --- |
| 401 | 10000 | 112 исходные 10000 | углубленно |
| 402 | 20000 | 113 исходные 20000 (после merge на каноне 112) | углубленно |

Две бывшие задолженности (112 и 113) стали одним `Dbt`; две строки Value и два комментария сохранились.
