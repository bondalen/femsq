# Заготовка: SQL Server 2012 SP4 (продуктив) → схема **`ags`**

**Решение владельца (S48a):** на проде объекты СУДЗ размещаются в **`ags`**, не в отдельной схеме `sudz`.

Скрипты корня пакета (`../`) используют схему **`sudz`** и синтаксис DEV (SQL 2022): `CREATE OR ALTER`, `DROP IF EXISTS`, `STRING_AGG` и т.п.

Перед продом:

1. Скопировать утверждённые объекты сюда.
2. Заменить квалификатор `sudz.` → `ags.` (и `SCHEMA`/`MS_Description` level0name).
3. Заменить `CREATE OR ALTER` → `IF OBJECT_ID… DROP` + `CREATE` (или `ALTER` при существовании).
4. Убрать/заменить конструкции новее 2012.
5. Согласовать пересечения с уже живыми `ags.invDbt`, `ags.cnInvCmm*`, `ags.yr` (оживление ALTER vs новые имена).
6. Прогнать на инстансе с `COMPATIBILITY_LEVEL = 110`.

**Пока пусто:** cutover 0066 на DEV выполнен в схеме `sudz` корневыми скриптами.
