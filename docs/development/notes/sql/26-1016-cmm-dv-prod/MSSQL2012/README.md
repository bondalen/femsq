# MSSQL2012 — Acc → *Dv walk-back

Единственный набор для FishEye. Синтаксис SQL Server 2012: без `CREATE OR ALTER`, без `DROP IF EXISTS`, без `STRING_SPLIT`.

Порядок: `00` → `01` (смотреть глазами) → бэкап → `02` → `03`. `04` данные не меняет.

Схема в скриптах — `sudz`. Если `00` пишет `gate FAIL`, колонок `*Dv` на контуре нет: DML не запускать.
